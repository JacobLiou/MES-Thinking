    S1[①问六问<br/>圈定业务范围] --> S2[②识别对象<br/>定义层/执行层/记录层]

## 2. 方法论要点

<!-- 待填充 -->

- 从「追溯问题清单」（06.1）反推模型完整性：回答不了的每问，都指向缺失的模型
- 先记录、再约束、后分析：模型先支持事实采集，再收紧约束（对应 M1→M2）
- 先小后大：单线体闭环验证后再横向复制（对应「先小后大」原则）
- 模型稳定性优先于功能丰富度

## 3. 建模完成度检查清单

<!-- 待填充：逐项可打勾 -->

- [ ] 每个状态机都有终态，且终态不可逆
- [ ] 每次状态迁移都对应一个事件（可追溯）
- [ ] 每个事件都携带 5M1E 上下文
- [ ] 每个写操作都有幂等键
- [ ] 反向追溯：任意 SN 可回答 17 问（06.1 清单）
- [ ] 正向追溯：任意 Lot / 设备 / 模板可扩散到受影响 SN 集合
- [ ] 每个处置路径都有审批与留痕
- [ ] 主数据（定义层）与过程数据（执行/记录层）分离
- [ ] 错误码与业务规则一一对应（`MES-xxxx`）
