# 07.2 VOA 产品生命周期业务建模

> 所属篇章：07_综合案例 ｜ 状态：✅ 已完成

> VOA = Variable Optical Attenuator（可变光衰减器），光通信器件。本篇以 VOA 为例，将 00–06 的通用模型实例化。

## 本篇要回答的业务问题

- VOA 的产品 / BOM / 测试规格如何映射到 What 模型？
- VOA 的制造流程与测试参数如何映射到 WhatToDo / Expected-Actual？
- VOA 的典型失效模式如何映射到质量与追溯模型？

## 1. VOA 产品与 BOM（What）

| 建模要素 | VOA 实例化 | 模型篇目 |
| --- | --- | --- |
| 产品型号系列 | 机械可调 / 电动可调；通道数 1/2/4 | [01.1 ProductType](../01_What_应该生产什么/01.1_产品Product模型.md) |
| 关键子件 | 光缆、准直器、衰减芯片 / 机械调节机构、连接器、外壳 | BOMLine |
| BOM 特点 | 通道位号敏感 | BOMLine.Position |
| 谱系特点 | 关键子件需单件 / 批次级追溯 | GenealogyLink.ChildType |

实例化后的 BOM 片段（VOA-100G-C，4 通道）：

```text
VOA-100G-C（成品）
 ├── 衰减芯片 ×4     [Position: CH1–CH4]  [批次管控·关键料]
 ├── 准直器 ×4       [Position: CH1–CH4]  [单件追溯·关键料]
 ├── 机械调节机构 ×1  [批次管控]
 ├── 光缆 ×2         [批次管控]
 ├── 连接器 ×2       [批次管控]
 ├── 外壳 ×1         [批次管控]
 └── 胶水（辅料）     [替代组：A 胶 / B 胶]
```

VOA BOM 的两个行业特性：

1. **通道位号（Channel Position）敏感**：同一型号的 4 通道，每通道插损独立测量与判定——位号编码（CH1–CH4）必须从 BOM 一路贯通到缺陷位置（05.3）与谱系（06.2），否则「CH2 通道异常」无法定位到「CH2 位置的料」；
2. **关键料集中在衰减芯片与准直器**：这两类料的批次/单件追溯是客诉与召回的主战场——`LotControlled` / `SerialTraced` 强制开启（01.2 §4.2）。

## 2. VOA 制造流程（WhatToDo）

示例流程（按实际产线调整）：

```mermaid
flowchart LR
    A[组装] --> B[调试 / 校准]
    B --> C[环境适应]
    C --> D[终测]
    D --> E[外观检验]
    E --> F[包装]
```

映射到 TestFlow / RouteStep：

| 步骤 | StepNo | 类型 | 工站示例 | 模型要点 |
| --- | --- | --- | --- | --- |
| 组装 | 10 | PassOnly | ASSY-01 | 上料与谱系绑定的发生地（06.2 §2） |
| 调试 / 校准 | 20 | PassOnly | TUNE-01 | 机械调节机构定位精度；**返工的常见回退点** |
| 环境适应 | 25 | PassOnly | CHMB-01 | 温循 / 老化——批量工序，时间窗与配方绑定（环境证据，03.4 §3） |
| 终测 | 30 | TestRequired | FT-01 | 光 + 电全参数测试，本流程的判定核心 |
| 外观检验 | 40 | PassOnly | VIS-01 | 人工检验（无仪器 → 5M1E 的 Machine 维为空） |
| 包装 | 50 | PassOnly | PKG-01 | 末站，完成后 Done |

对照战略文档的典型测试链（`从MIMS到MES` §5.1-D：组装过站 → 电性能初测 → 光性能测试 → 温循/老化 → 终测 → 外观/包装 → Done）——本例将「电性能初测 + 光性能测试」合并为「终测」作简化；多站拆分时的建模不变。

## 3. 测试参数与规格（Expected）

| 参数 | 说明 | 规格示例（占位） |
| --- | --- | --- |
| IL 插入损耗 | 通道插损 | ≤ x dB @ 1550nm |
| RL 回波损耗 | 反射 | ≥ x dB |
| 衰减量 / 衰减精度 | 设定衰减与偏差 | ± x dB |
| PDL 偏振相关损耗 | 极化依赖 | ≤ x dB |
| 重复性 | 可调重复定位 | ± x dB |

- **TestTemplate / TestBatchId 与本仓库测试模型的映射**：

| 通用模型 | 本仓库落点 | 说明 |
| --- | --- | --- |
| TestTemplate（测试模板版本） | 上位机侧持有，版本随上传上下文记录（M2 结构化） | 「怎么测」 |
| Spec（规格版本） | `SpcRule` 控制限先行 + 完整规格 M2 | 「怎么判」 |
| TestBatchId | `TestRecord.TestBatchId`（幂等键三元组之一） | 一次测试的唯一业务身份 |
| SpecItem（IL/RL/PDL…） | `TestRecord.Metrics` 的键（指标字典） | 参数名统一治理是 SPC 前提 |

- **规格的通道维度**：多通道产品的 SpecItem 应按 (Parameter × Channel) 展开（如 `IL@CH2`）或以位号后缀编码——与 BOM 位号、缺陷位置同构。

## 4. 典型失效模式（WhatActuallyHappened）

| 失效模式 | 现象 | 排查路径（模型联动） | 返工路径 |
| --- | --- | --- | --- |
| 插损超标（IL-HIGH） | 某通道 IL 超上限 | 位号 → 谱系 → 该位置的准直器/芯片批次；对照同批次其他 SN（正向扩散） | Rework 回调试站重新校准；换料则更新谱系 |
| 衰减精度漂移（ATT-DRIFT） | 设定值与实测偏差大 | 调试记录 → 调试工位/治具（03.3 治具换型记录） | Rework 回调试站 |
| 回损不良（RL-LOW） | 反射超标 | 端面清洁工艺 → 操作员（03.2）→ 装配 SOP 版本 | 清洁后 Retest（新批次） |
| 通道串扰（XTALK） | 通道间隔离度差 | 结构设计 / 装配位置 → 位号分析 | 多为设计问题 → NC 单 + 工程 |
| 温循后漂移 | 环境适应后参数变化 | 温循曲线（03.4 环境证据）+ 时段关联 | Rework 或报废评估 |

对应的 DefectCode 体系（05.3 §2 的实例化）：`FT-IL-HIGH`、`FT-ATT-DRIFT`、`FT-RL-LOW`、`FT-XTALK`、`FT-TEMP-DRIFT`——站别前缀 + 失效模式。每个失效模式预设「排查路径」与「返工路径」的意义：**失效模式知识库是 MES 从「记录」走向「分析」的沉淀物**（第三阶段 M3 的价值形态）。

## 5. VOA 的追溯要求（CanWeProveIt）

光通信行业客户的常见追溯要求（示例条款化）：

| 客户要求 | 模型支撑 | 状态 |
| --- | --- | --- |
| 任意 SN 提供 5 年内完整制造履历 | 事件 + 记录 + 归档（00.3 EOL；06.1 §3 冷热分层） | ⏳ M1 已有骨架 |
| 关键料（衰减芯片 / 准直器）批次可正反追溯 | Genealogy 双向查询（06.3） | ⏳ 待上料记录 |
| 测试原始数据可供审核 | RawPayload + 证据链（06.4） | ✅ 双轨已实现 |
| 返工 / 让步记录含审批人 | DisposalEvent + 审批（05.4） | ⏳ M2 |
| 制造用设备与程序版本可出示 | 事件上下文快照（03.4 / 03.3） | ⏳ M2 |

**关键料（衰减芯片批次）的正反向追溯演练**——用 [07.1](07.1_一个产品的一生.md) 的案例数据：

- 反向：`VOA261030-0001` → 谱系树 → 衰减芯片 `L-7712`（CH1–CH4 各一颗）+ 准直器 `C-1108` 等；
- 正向：`L-7712` → 12 台成品（在制 3 / 在库 8 / 发货 1）→ 分级处置。

VOA 生命周期对照（00.3 的实例化）：试产期弱门控跑通 EVT/DVT → PVT 收紧门控与 SPC → 量产期 ECN 管理（如换衰减芯片供应商：**按 SN 切割**，因为影响测试规格与判定）→ EOL 后追溯数据保留 5 年。
